# Kap1 Paper scRNA and scMultiome Analysis 

This repository contains the code to reproduce the analysis in the following paper: 
**Kap1 maintains chromatin structure to ensure high fidelity hormone receptor signaling in the mammary gland**
Michael JG Milevskiy, Hao-Chun Chang, Felicity C Jackling, Felicia Ong, Malindrie Dharmaratne, Caleb Dawson, Somayeh Kordafshari, Elliot Surgenor, Minhsuang Tsai, Francois Vaillant, Hannah Coughlan, Lachlan Whitehead, Laura Marruecos, Geoffrey J Lindeman, Yunshun Chen

Each subfolder has its own README with setup and run instructions:
1) [`KAP1_scRNA_analysis/`](./KAP1_scRNA_analysis) 
2) [`KAP1_multiome_analysis/`](./KAP1_multiome_analysis)
