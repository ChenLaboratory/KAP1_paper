# Kap1 Paper scRNA and scMultiome Analysis 

Analysis code for the single-cell profiling of WT vs. *Kap1/Trim28* KO
mouse mammary gland described in [paper citation/link].

This repository contains two analysis pipelines:

- [`scRNAseq/`](./KAP1_scRNA_analysis) 
- [`scMultiome/`](./KAP1_multiome_analysis) 

Each subfolder has its own README with setup and run instructions.
